# Requisitos
- Todo el desarrollo este hecho con node, tanto frontend como backend 
- Debe hacerse uso de typescript
- El frontend debe ser hecho con react
- El backend debe ser hecho con express
- La base de datos debe ser SQLite
- Las librerias a usar son las más estable y actualizadas
- Las contraseñas deben ser seguras
- Todos los archivos con extension .md deben guardarse en la raiz del proyecto
- Siempre realiza push a github https://github.com/Nico961003/wabis
